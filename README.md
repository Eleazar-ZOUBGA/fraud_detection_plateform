# Real-Time Fraud Detection Platform

A production-grade Machine Learning system designed to detect fraudulent credit card transactions in real time.

**Key Highlights:**
- **Core Architecture:** PostgreSQL, XGBoost/LightGBM, FastAPI, Docker & AWS.
- **MLOps Focus:** MLflow experiment tracking & Model Registry, automated CI/CD via GitHub Actions.
- **Metric Targets:** Optimized for PR-AUC & Recall on highly imbalanced data (~0.17% fraud rate).
